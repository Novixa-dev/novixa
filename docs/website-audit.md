## ١. ملخص التدقيق التنفيذي (Executive Summary)

يمتلك مشروع نوڤيكسا (`Novixa`) قاعدة معمارية وهندسية عالية الجودة مبنية باستخدام **Next.js 15 (App Router)** و **TypeScript** و **Tailwind CSS v4** و **Docker (Multi-stage standalone)** على بنية خادم مستقل (VPS) مع قاعدة بيانات **PostgreSQL** وخادم بريد محلي متصل عبر **mailcow (SMTP)**، مع تطبيق صارم لقواعد الأمان ومكافحة الادعاءات غير الموثقة (`Anti-Fabrication & Anti-Slop`).

ومع ذلك، أظهر التدقيق العميق الشامل وجود **فجوات جوهرية** بين ما تتطلبه وثيقة التحسين الشاملة (`Master Prompt`) والوضع الفعلي، أبرزها:

1. **قصور لوحة الإدارة (`/admin`) في العمليات التشغيلية (CRUD):**
   - لوحة الإدارة كانت تركز فقط على قراءة طلبات التواصل (`Leads`) وتعديل بعض حالاتها.
   - **غياب إمكانية إنشاء طلب عميل يدوياً (`Manual Lead Creation`):** عندما يتصل عميل هاتفياً أو عبر واتساب أو مقابلة مباشرة، لا يملك المسؤول أي وسيلة لإدخال الطلب وتوثيقه في النظام.
   - **واجهة الكتالوج والخدمات (`/admin/services`):** كانت مجرد صفحة عرض ثابتة (Read-Only) تقرأ من مصفوفات برمجية مجمدة (`data.ts`)، دون أي إمكانية للإضافة، التعديل، الحذف، أو تغيير حالة التفعيل.
   - **غياب أقسام الإدارة للمحتوى الأساسي:** لا يوجد في لوحة الإدارة واجهات لإدارة الأسئلة الشائعة (`FAQs`)، أو الرؤى والمقالات التقنية (`Insights/Articles`)، أو معرض المشاريع وحالات الدراسة (`Case Studies`).
   - **غياب نظام إدارة برنامج الشركاء والعمولات (`Affiliate & Partner Ledger`):** المنصوص عليه بالبند ١٢ في وثيقة الماستر، بنسبة عمولة ٣٠٪ وحسابات مدققة.
   - **غياب نظام إدارة المبادرات المجتمعية وحملات الهدايا (`Community Campaigns & Grants`):** المنصوص عليه بالبند ١٣ لمراجعة الطلبات والمنح البرمجية.

2. **اعتماد المحتوى على الملفات الثابتة (`Content-as-Code`):**
   - تعديل أي نص أو خدمة أو منتج كان يتطلب تعديلاً في الكود ورفع PR وإعادة بناء كامل للموقع، مما يعطل سرعة الأعمال والمبيعات.
   - الحاجة لبناء طبقة تخزين ديناميكية (`Content & Catalog Store`) تدعم التهيئة الفورية من الكود القائم، وتتيح عمليات الـ CRUD للمسؤول عبر واجهة الإدارة، وتعمل في بيئة PostgreSQL كما تعمل في بيئة الذاكرة للتطوير والاختبارات.

## ٢. تدقيق البنية التحتية والاعتماديات البرمجية

| المكون | الواقع الفعلي | التقييم الهندسي | الملاحظات |
|---|---|---|---|
| **Framework** | Next.js 15.5.4 (App Router) | ممتاز | أحدث إصدار معالجة للثغرات، SSR و RSC بالكامل |
| **Language** | TypeScript 5.8.2 (Strict) | ممتاز | فحص الأنواع (`typecheck`) يمر بنجاح 100% |
| **Styling** | Tailwind CSS v4 + Vanilla CSS | ممتاز | تم الالتزام بلوحة الألوان (`#020617`, `#2563EB`, `#14B8A6`) دون تدرجات بنفسجية |
| **Typography** | Alexandria + IBM Plex Sans Arabic + Inter | ممتاز | محملة محلياً عبر `next/font` لسرعة التحميل وانعدام الاعتماد الخارجي |

## ٣. تدقيق واجهة وتجربة المستخدم العامة (Public UI/UX Audit)

### النقاط القوية:
- **العربية لغة أساسية أولى (Arabic-First):** التوجيه المنطقي، استخدام `t(ar, en)`، وخطوط متناسقة تمنع تداخل الحركات والتنوين في العناوين العريضة.
- **التوازن البصري (Anti-Slop):** غياب العناصر الهلامية والزخارف المبتذلة، مع بطاقات نظيفة `.glass-card` بلا إجهاد لمعالجة الرسوميات `backdrop-filter`.
- **لوحة الأوامر السريعة (`Ctrl+K`):** توفر وصولاً فورياً لكافة أقسام الموقع والمنتجات.
- **إثباتات حقيقية بدون تزييف:** نموذج عرض لوحة التحكم (`/ar/dashboard`) يحمل تنبيهاً واضحاً ومقروءاً بأنه نموذج بيانات توضيحي تفاعلي.

### الفجوات المرصودة المطلوب معالجتها:
1. **تحديث مسار منتج نوفكسا عقار (`Novixa Aqar`):**
   - توضيح السعر المبدئي للترخيص المخصص (يبدأ من 500 دولار أمريكي) مع توضيح نطاق التسليم (كود مصدري أو ترخيص منشور مخصص) بدلاً من تركه كاشتراك شهري مبهم.
2. **تحديث وضع منتج مهاجم (`Muhajim`):**
   - اعتباره منتجاً مجانياً متاحاً للاستخدام وفق توجيهات المالك، وربطه بمستودعه ورابطه الرسمي عند التحقق.
3. **ضبط وضعية منتج نبض (`Novixa Pulse`):**
   - تثبيت حالته كمنتج قيد التطوير الداخلي / فكرة برمجية مستقبلية، وعدم الترويج له كحل سحابي مفعل بالكامل لتجنب خرق قواعد النزاهة الهندسية.

## ٤. تدقيق لوحة الإدارة (`/admin`) ومتطلبات الـ CRUD الكاملة

| الوظيفة / القسم | الوضع السابق | المتطلب المهني الشامل | الإجراء المطلوب |
|---|---|---|---|
| **إدخال الطلبات يدوياً** | غير موجود إطلاقاً | زر "إضافة طلب جديد" مع نموذج إدخال كامل يسجل في الـ Store مع التوثيق الآلي | تنفيذ `createLeadManual` مع نافذة منبثقة تفاعلية |
| **تعديل تفاصيل الطلب** | مقتصر على الملاحظات والوسوم | إمكانية تعديل الاسم، الهاتف، الشركة، الميزانية، وتفاصيل المشروع | تنفيذ `updateLeadDetails` في لوحة الإدارة |
| **إدارة الكتالوج والخدمات** | قراءة فقط من `data.ts` | لوحة إدارة كاملة للخدمات والحلول والمنتجات مع إمكانية الإضافة والتعديل والحذف وتغيير الحالة | بناء واجهة تفاعلية مع Server Actions لإدارة الكتالوج |
| **إدارة الأسئلة الشائعة** | غير موجود في الإدارة | إدارة تصنيفات الأسئلة، إضافة سؤال وجواب بالعربية والإنجليزية، وتعديلها وحذفها | إنشاء قسم `/admin/faq` مع تحكم CRUD كامل |
| **إدارة المقالات والرؤى** | غير موجود في الإدارة | إضافة مقالات تقنية جديدة، تحديث مدة القراءة، تعديل المحتوى، النشر أو الأرشفة | إنشاء قسم `/admin/insights` مع تحكم CRUD كامل |
| **إدارة سابقة الأعمال** | غير موجود في الإدارة | إضافة حالات دراسة ونماذج معمارية جديدة، تحديث الروابط والتصنيفات | إنشاء قسم `/admin/work` مع تحكم CRUD كامل |
| **برنامج الشركاء والعمولات** | غير موجود في الإدارة | تسجيل الشركاء، نسبة العمولة (30% افتراضياً)، تسجيل المبيعات المحققة، سجل العمولات وحالة الصرف | إنشاء قسم `/admin/affiliates` بدقة حسابية كاملة |
| **المبادرات المجتمعية** | غير موجود في الإدارة | إدارة حملات هدايا المواقع للمطورين والمبادرات، فرز المتقدمين، قبول/رفض الطلبات | إنشاء قسم `/admin/campaigns` مع سجل تدقيق |

## ٥. خطة التنفيذ الفورية

1. **توثيق مرجع الحقيقة والادعاءات:** إنشاء `docs/source-of-truth.md`.
2. **توثيق خارطة الطريق المحدثة:** إنشاء `docs/implementation-roadmap.md`.
3. **توثيق المعمارية البرمجية لعمليات الـ CRUD:** إنشاء `docs/ADMIN_DASHBOARD_CRUD_ARCHITECTURE.md`.
4. **تأسيس طبقة التخزين الموحدة للكتالوج والمحتوى (`Content & Catalog Store`):** في `src/lib/content-store/` مع دعم التخزين الثنائي (PostgreSQL + In-memory Seeder).
5. **تنفيذ Server Actions الموسعة:** لجميع عمليات الإنشاء والتعديل والحذف.
6. **بناء وتحديث واجهات لوحة الإدارة:**
   - تحديث `/admin/leads` بإضافة نموذج إنشاء الطلبات اليدوي وتعديل البيانات.
   - تحويل `/admin/services` إلى نظام إدارة تفاعلي كامل يدعم الـ CRUD.
   - إنشاء صفحات الإدارة الجديدة: `/admin/faq`، `/admin/insights`، `/admin/work`، `/admin/affiliates`، `/admin/campaigns`.
   - تحديث شريط التنقل الجانبي `AdminShell`.
7. **إجراء الفحوصات الشاملة (Typecheck, Lint, Tests, Build) والتحقق من عدم حدوث أي انحدار (No Regressions).**
8. **الحفظ والدمج في Git والمزامنة مع GitHub.**
